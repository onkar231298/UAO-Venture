You are building the backend admin system for a B2B e-commerce and product document platform like Green Jeeva. The platform sells organic herbs, spices, powders, and botanical ingredients. This module is called "Website Management (Backend)", and it will allow Admins and Managers to control the content shown on the main website.

🧠 TASK:
Build the backend system to manage the frontend of the website — including product uploads, sliders, SEO metadata, documents, stock, pricing, categories, and product visibility. 

🎯 PURPOSE:
Enable full backend control to start uploading products and homepage content immediately, like:
- Product Listings
- Product Detail Pages
- Hero Slider Section
- Category & Tag Management
- SEO for each product page

---

### 🔹 SECTION 1: Product Upload Panel (Backend)

Allow Admin or Manager to upload and manage product information with the following fields:

1. ✅ Product Name  
2. ✅ Product Image (main display image)  
3. ✅ Product Gallery Images (multiple optional images)  
4. ✅ Category (e.g. Herbal Powder, Whole Spices, etc.)  
5. ✅ Product Type (Organic/Conventional)  
6. ✅ Product Grade (Food Grade, Pharma Grade, etc.)  
7. ✅ Certifications (multiple select: NOP Organic, EU Organic, USDA, FSSAI, Kosher, Halal, etc.)  
8. ✅ Country of Origin  
9. ✅ HS Code  
10. ✅ Specification Sheet (HTML input with preview support like Green Jeeva)  
11. ✅ Upload Documents (PDF format):  
    - COA  
    - Organic Certificate  
    - Technical Sheet  
    - MSDS/SDS  
    - Allergen Statement  
    - Others (user can define title)  
12. ✅ Stock Availability  
    - Current Stock (in KG or MT)  
    - MOQ (Minimum Order Quantity)  
    - Lead Time (in days or weeks)  
    - "Sample Available" toggle  
    - "Stop Sell" toggle  
13. ✅ Pricing  
    - Per KG or MT pricing  
    - Currency type  
    - Bulk pricing slabs (e.g., 100–500 kg, 500–1000 kg)  
    - Pricing visibility control (only for logged-in users)  
14. ✅ Product Slug URL (auto-generated from name, can be edited)  
15. ✅ SEO Meta Data:  
    - Meta Title  
    - Meta Description  
    - Canonical URL  
    - Open Graph image (optional)  
    - Structured data schema for Google Rich Results  
16. ✅ Visibility Status  
    - Show / Hide on Website  
    - Status: Active / Draft / Inactive  
17. ✅ Internal Notes (for internal use, not visible on frontend)

---

### 🔹 SECTION 2: Product ID & Internal Linking

- Auto-generate unique Product ID for each product.
- This ID will be reused across CRM, Inventory, Orders, and Enquiries.
- Enable internal linking of product ID to other system modules.

---

### 🔹 SECTION 3: Category & Tag Manager

Allow Admins to:
- Create and edit categories (Herbal Powder, Whole Herbs, etc.)
- Assign tags (e.g., Organic, USDA, In Stock, Antioxidant, etc.)
- Tags should be used for frontend filters and SEO.
- Reusable tags available in dropdown.

---

### 🔹 SECTION 4: Product Documents & Specification Preview

- Allow upload of PDF documents and associate them with each product.
- Also allow **HTML input for specification** (copy-paste from Word or styled template).
- The frontend should render this as a **specification preview table** (like Green Jeeva).
- Allow batch-specific uploads or versioning (optional).
- Add Document Title + Upload field + Visible to User toggle.

---

### 🔹 SECTION 5: Hero Section Slider Management (Homepage)

Add backend UI for Hero Slider control. Each slider should support:

1. ✅ Upload Image (1920x600 or flexible)
2. ✅ Heading Title
3. ✅ Subheading or CTA Text
4. ✅ Button Text
5. ✅ Button URL (internal or external)
6. ✅ Status (Active / Inactive)
7. ✅ Order Position (1st, 2nd, 3rd, etc.)
8. ✅ Scheduling (optional start and end date)

Enable Admin/Manager to upload multiple sliders. The frontend homepage should dynamically fetch only **Active** and **Scheduled** sliders and show them in the homepage carousel.

---

### 🔹 SECTION 6: Frontend Integration Requirements

- All fields from backend should sync with the product detail page like this reference:
🔗 https://www.greenjeeva.com/product/organic-turmeric-root-powder/onh/112023913/66806802

- Display Product Image, Name, Certifications, Available Stock, Country of Origin, and Key Attributes.

- Specification Sheet should render cleanly as HTML preview.

- Documents (COA, Organic Cert, etc.) should show in a **Download Section** on product page.

- Meta title, description, and canonical URL must reflect per-product SEO setup.

---

### 🧑‍💼 Roles and Access

- Super Admin: Full access to Website Management backend
- Manager: Can create/edit products and sliders
- Executive: Can only view products or upload documents (permission-based)

---

💡 Once this backend is created, Admin can immediately begin uploading products, creating product pages, and managing homepage slider banners.
