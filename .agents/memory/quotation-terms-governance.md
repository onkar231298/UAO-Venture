---
name: Quotation terms governance
description: Review, versioning, and acceptance rules for general sales quotation terms.
---

The user chose a pending-approval workflow for the supplied sales terms. Keep proposed text inactive until an administrator records legal review and an effective date. Preserve the exact terms text and version on each quotation when it is issued; record acceptance only on an explicit customer acceptance event, not on PDF generation, download, or email.

**Why:** The user selected the pending-approval option, and the supplied terms brief says the wording needs legal review before activation and historical quotations must remain reproducible.

**How to apply:** Future wording changes create a new version rather than editing issued snapshots. Only an approved active version applies to quotations first issued under it. Do not add or change email delivery unless requested.

The user wants quotation terms and future reusable templates managed together under the admin System Settings > Template Management area, rather than scattered through operational menus.

**Why:** the user expects more template types and wants one place to keep them updated.

**How to apply:** add future reusable template managers to the Template Management library in Settings.

Quotation PDF layouts are managed separately from terms in the same library. Super admins can create and preview draft versions before activation; the authorised acceptance/signature page stays required, and issued quotations keep the layout snapshot used when sent.

**Why:** the user wants a central place for multiple future templates and requires an authorised acceptance page on quotations; activating a new layout must not silently restyle issued documents.

**How to apply:** keep legal terms versioning separate from visual PDF settings, preserve the required signature page, and snapshot the active PDF settings when a quotation is issued.
