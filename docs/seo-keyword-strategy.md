# B2B SEO keyword strategy

Applied on September 7, 2026.

## Evidence and safeguards

- The imported Google Search Console performance table contained no rows, so no ranking or click claims were used to justify replacing a target.
- Existing published blog metadata was retained because it already had distinct informational intent.
- Product metadata was replaced only when it was missing, exactly matched the current generator, or matched a known legacy title-and-description pair.
- The rollout command supports a non-writing preview (`npm run seo:preview-strategy`) and requires an explicit apply command (`npm run seo:apply-strategy`).
- Regional pages use factual sourcing language and tell buyers to confirm current product documentation and regulatory suitability.
